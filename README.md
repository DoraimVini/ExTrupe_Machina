# Trupe Br — Multi-Agent Harness 🧶🤖

## O que estamos fazendo?
Estamos construindo uma **Central de Orquestração Inteligente** para a **Trupe Br**, uma marca de moda artesanal e sofisticada. O sistema utiliza múltiplos agentes de IA especializados para automatizar a operação da marca, desde o atendimento ao cliente até o controle de estoque em tempo real.

## Para que serve?
O objetivo é escalar a operação da Trupe Br sem perder o toque humano e a organização. O sistema resolve os seguintes problemas:
- **Gestão de Estoque Ominicanal**: Sincronização automática entre vendas em feiras (offline), site (Nuvemshop) e controle interno (Notion).
- **Atendimento Ágil**: Respostas rápidas a dúvidas de clientes via WhatsApp/Instagram sobre materiais, preços e frete.
- **Inteligência de Negócio**: Auditoria semanal de vendas para prever demanda e otimizar a produção artesanal.

## Estrutura do Sistema (Agentes)
- **Orquestrador**: O cérebro que recebe inputs e direciona para o agente correto.
- **Agente de Atendimento**: Focado na experiência do cliente e suporte.
- **Agente de Estoque**: Integrado via API ao Notion para controle de peças e SKUs.
- **Agente de Auditoria**: Analisa logs e gera insights estratégicos.

## Tecnologias Utilizadas
- **Python 3.12**: Linguagem base do sistema.
- **Notion API**: Banco de dados centralizado.
- **Glassmorphism Dashboard**: Interface visual de monitoramento.
- **Multi-Agent Framework**: Arquitetura modular de agentes independentes.
